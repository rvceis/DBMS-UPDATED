TROUBLESHOOTING
===============

If setup fails:

1. Check backend logs for errors
2. Verify credentials are correct
3. Make sure database connection is working
4. Check all three services are running (backend, frontend, database)
5. Try clearing browser cache and refreshing

If data doesn't appear:

1. Check browser console for errors
2. Verify records were created (check server logs)
3. Clear local storage and refresh
4. Try filtering to "All" asset types
5. Check schema was created successfully
