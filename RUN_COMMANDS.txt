TROUBLESHOOTING COMMANDS
========================

If something goes wrong:

1. Check backend logs:
   Look at Terminal 1 output for errors

2. Check frontend build:
   Look at Terminal 2 output for warnings

3. Check database:
   Setup script output will show errors

4. Clear browser cache:
   DevTools > Application > Clear Storage > Clear All

5. Check port conflicts:
   ```
   lsof -i :5000    # Check if port 5000 in use
   lsof -i :5173    # Check if port 5173 in use
   ```

6. Restart everything:
   - Stop all three terminals (Ctrl+C)
   - Wait 5 seconds
   - Restart from Step 1
