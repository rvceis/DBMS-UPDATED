def _parse_hierarchical_text(self, content: str) -> List[Dict[str, Any]]:

    records = []

    for line in content.split('\n'):
        if not line.strip():

        indent = len(line) - len(line.lstrip())
        stripped = line.strip()
        match = re.match(r'([^:=]+)\s*[:=]\s*(.+)', stripped)
        
        if match:
            key = match.group(1).strip()
            value = match.group(2).strip()

                # Top-level: stores in JSON as-is
                current_parent_key = key

                if current_parent_key not in current_record:

        elif stripped.startswith('-') and ':' in stripped:

#### Method 2: `_infer_value_type()`
Converts string values to proper types:

```python
def _infer_value_type(self, value: str) -> Any:
    """Infer and convert value to appropriate Python type"""
    value = value.strip()
    
    if value.lower() in ['true', 'yes', '1']:
        return True
    elif value.lower() in ['false', 'no', '0']:
        return False
    elif value.lower() in ['null', 'none', '']:
        return None
    
    try:
        if '.' not in value:
            return int(value)
    except ValueError:
        pass
    
    try:
        return float(value)
    except ValueError:
        pass
    
    return value  # Default to string
```

**Result**: When imported, text files are converted to properly structured JSON with:
- Nested objects preserved
- Arrays as native JSON arrays
- Types properly inferred (not everything as string)
- Relationships maintained within document

## How It Works

### Import Flow

```
Text File (hierarchical/indented)
    ↓
Format Detection
  → Detects: 'structured_text'
    ↓
Hierarchical Parser (_parse_hierarchical_text)
  → Reads indented blocks
  → Creates nested objects: {parent: {child: value}}
  → Creates arrays: [{item1}, {item2}]
    ↓
Type Inference (_infer_value_type)
  → true/false → Boolean
  → 123 → Integer
  → 45.6 → Float
  → text → String
    ↓
JSON Document
  → One document per entity
  → Full structure preserved
  → No flattening
    ↓
Database Storage (JSONB)
  DataRow.data = complete JSON document
    ↓
Schema Generation
  → Extract field names from JSON keys
  → Infer types (string, integer, array, object)
  → Create schema automatically
```
