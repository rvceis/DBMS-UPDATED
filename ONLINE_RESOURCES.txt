HOW TO DOWNLOAD & IMPORT:
================================================================================

For 3D Models (GLTF/OBJ):
  1. Download .gltf, .obj, .fbx files
  2. Create schema for "3D Model" asset type
  3. Use populate_database.py to add records
  4. Upload files via frontend or import tool

For Datasets (CSV/JSON):
  1. Download CSV or JSON file
  2. Create schema matching your data structure
  3. Use populate_database.py with the CSV/JSON
  4. Data automatically validates against schema

For Code:
  1. Clone repository: git clone <url>
  2. Create "Source Code" asset type
  3. Upload code files as records
  4. Store metadata about the code

For API Specs:
  1. Download OpenAPI/GraphQL definitions
  2. Create "API Specification" asset type
  3. Store spec as JSON/YAML in records


RECOMMENDED WORKFLOW:
================================================================================

1. Start:
   python3 populate_asset_types.py

2. Browse online for assets you want:
   - Sketchfab for 3D models
   - Kaggle for datasets
   - GitHub for code

3. Download samples (free always available):
   - Download 1-2 3D models
   - Download 2-3 CSV datasets
   - Clone 1 GitHub repo

4. Create schemas for each type:
   - 3D Model schema (with format, size fields)
   - Dataset schema (with row_count, columns fields)
   - Code schema (with language, lines_of_code fields)

5. Populate database:
   python3 populate_database.py

6. View results in frontend:
   - Check Schemas page
   - Check Data page
   - Filter by asset type
